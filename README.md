# Rautahat Panmasala

Company website for Rautahat Pan Masala Udhyog Pvt. Ltd., built with Next.js. It introduces the brand, shares the company story and contact email, and provides a products page for collection updates.

## Requirements

- Node.js (LTS recommended)
- npm

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Available commands

| Command | Description |
| --- | --- |
| `npm run dev` | Start the local development server |
| `npm run build` | Create a production build |
| `npm run start` | Serve the production build locally |
| `npm run lint` | Run ESLint |

## Project structure

- `src/app/page.tsx` - Home page, company story and contact details
- `src/app/products/page.tsx` - Product collection updates
- `src/app/globals.css` - Global styles
- `src/components/` - Shared page components
- `public/` - Static images and brand assets

## Tech stack

- Next.js 16 with the App Router
- React 19
- TypeScript
- Tailwind CSS 4
